# Mira antes de disparar

Aplicación web móvil para aprender fotografía aprendiendo a mirar.

- 3 niveles (Básico, Medio, Avanzado) con 15 módulos, todos abiertos.
- Cada lección sigue el método: Aprender → Observar → Explorar → Experimentar → Fotografiar → Reflexionar → Retroalimentación.
- Fotos con la cámara del celular o desde la galería.
- Progreso, fotos y reflexiones guardados en el navegador (localStorage).

Es un único archivo `index.html`, sin dependencias ni proceso de build. Se publica con GitHub Pages desde la rama `main`.
